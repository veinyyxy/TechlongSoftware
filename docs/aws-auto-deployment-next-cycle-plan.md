## 6. 时序：准备不消耗短窗口，短窗口内只执行

设实际云Review生成时刻为R、原claimBy=C=R+15分钟、workload到期为W、basis到期为B：

- 原发布预算终点 `E=min(当前核验时刻+2小时, B, C-8分钟, W-90分钟)`；不改这些规则。
- 原三写发布最晚启动早于 `E-2分钟`；通常约为R+5分钟，而不是R+15分钟。该点必须在开窗前让代理和用户理解。

- 总清单缺件、源/角色/业务漂移、没有本人审批、失败或提交不明，立即停止并保留阶段/ACK；不得自动新任务、新窗口或重放。停止后再按手册诊断，不复制固定任务分支。
